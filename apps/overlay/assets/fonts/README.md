# Inter

The Chat screen uses Inter from the Paper Workbench explorations. These unmodified
variable fonts come from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter)
and are distributed under the SIL Open Font License in [OFL.txt](OFL.txt).

`panel.ts` registers them for the app process. The build copies this directory into
`Contents/Resources/fonts`; nothing is installed into the user's font library.
